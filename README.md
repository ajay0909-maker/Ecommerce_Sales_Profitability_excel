# E-Commerce Sales & Profitability Analysis Dashboard

## 📊 Project Overview

This project is an **Excel-based E-Commerce Sales & Profitability Dashboard** created for a Data Analyst portfolio.

The dashboard analyzes **10,000 e-commerce transactions** to understand sales performance, profitability, customer behavior, product performance, regional trends, and payment methods.

## 🎯 Business Objective

The objective of this project is to transform raw e-commerce transaction data into meaningful business insights using Microsoft Excel.

Key questions addressed:

- What is the total sales and total profit?
- What is the average order value?
- Which product categories generate the highest sales?
- Which categories generate the highest profit?
- Which regions perform best?
- How do sales change month by month?
- Which products are top performers?
- Which payment methods are most frequently used?
- How does discounting affect profitability?

## 📌 Key KPIs

The dashboard tracks:

- **Total Sales**
- **Total Profit**
- **Total Orders**
- **Total Quantity**
- **Average Order Value**
- **Profit Margin**

### Important Formulas

**Average Order Value**

`Total Sales / Total Orders`

**Profit Margin**

`Total Profit / Total Sales`
